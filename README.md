Exercício 1: Reverter os Caracteres de uma String
Descrição
A função recursiva recebe uma string e devolve seus caracteres em ordem inversa. O caso base ocorre quando a string tem 0 ou 1 caracteres. Caso contrário, o último caractere é extraído e concatenado com a recursão aplicada ao restante da string.

Exemplo
Entrada: "Exemplo"
Saída: "olpmexE"
#
Exercício 2: Soma de Números em uma Lista Aninhada
Descrição
A função recursiva soma todos os números em uma lista, mesmo que estejam dentro de sublistas. O caso base ocorre quando o índice atinge o final da lista. A função verifica se o elemento é uma lista ou um número e age de forma correspondente.

Exemplo
Entrada: [1, [2, 3], [4, [5]]]
Saída: 15
